Power grid frequency data base

Frequency time series from many synchronous areas around the world
and synchronized data from locations in the Continental European grid.

Detailed description of methodology, naming schemes and validation
can be found in the corresponding Data Descriptor:
[1]: 
Jumar, R., Maaß, H., Schäfer, B., Gorjão, L. R., & Hagenmeyer, V. (2020). 
Power grid frequency data base. arXiv preprint arXiv:2006.01771

List of directories and contents:
---------------------------------
FrequencyData:
	-> Subfolders named according to data descriptor:
	EE01
		-> .csv files with frequency measurements from the Baltic grid
	
	ES_GC01
		-> .csv files with frequency measurements from Grand Canaria
	
	...

Supplementary:
	AcquisitionSoftware
		-> Source code for building EDR_Scope_N, our software for data acquisition
			produces .csv files with frequency time series and .xml raw data files.
		-> Readme: Instructions on how to build and run the software
	
	DescriptorPrograms
		-> MATLAB code to produce the figures from the Data Descriptor [1]
	
	AuxiliaryFunctions
		-> MATLAB functions required to run the figure generation, import data etc.

		Figure_4
			-> Code to produce Figure 4

		Figure_5
			-> Code to produce Figure 4
		
		...

	FrequencyTimeSeriesFromRaw
		-> MATLAB code to calculate frequency time series from raw data files generated by EDR_Scope_N.
	
	Hardware
		-> Autodesk EAGLE files for PPS-ISO and AFE circuits
		-> AssemblyGuide.pdf: Instructions for building and configuring an EDR
		
	TestData
		-> Data for technical validation of the EDR instrument. Required for Figure 4 and Figure 5
	
	WikiPictures
		-> Images used for the wiki of this OSF repository
		
WaveformData
	-> Subfolders named according to data descriptor:
	EE01
		-> .csv file with voltage samples from Baltic grid campaign. File name encodes the recording time.
	
	ES_GC01
		-> .csv file with voltage samples from Grand Canaria campaign.  File name encodes the recording time.
	
	...

Wiki images
	-> empty (auto generated)
